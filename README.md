# Wachtlijsten zorgaanbieders Twente

Statische website voor Porkbun met een dagelijkse gegevenscontrole via GitHub Actions.

- `index.html`: openbare pagina
- `wachtlijsten_data.json`: laatst gepubliceerde gegevens
- `.github/workflows/update-wachttijden.yml`: dagelijkse update
- `wachtlijsten_server_v20.py`: lokale bronproxy en proxy voor GitHub Actions

Zie `LEESMIJ_WACHTLIJSTEN_v20.txt` voor de installatiestappen.
